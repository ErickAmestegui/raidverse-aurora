# Assets and third-party software

The artifact geometry, portal shader, particle behavior, icon SVG, CSS, interface copy and synthetic demonstration captures were authored for this project during this session. No third-party photo, music, video, streamer footage, game footage or AI-generated asset was added.

The interface uses installed system fonts. It does not require a font CDN or any paid runtime service.

Core software dependencies include React, React DOM, Three.js, ws, Zod and tsx. Development tooling includes TypeScript, Vite, Vitest and the React Vite plugin. Their own licenses and any transitive notices are distributed with their packages; inspect the lockfile and installed package license files when distributing dependencies. Do not represent dependency code as original RAIDVERSE work.

Twitch is an external provider. Connection requires a registered application and each user's explicit consent. The project does not claim affiliation, endorsement or certification. Check Twitch's brand/developer requirements before publishing promotional assets. Hackathon names identify the intended event; no event logo or organizer-owned asset was copied into the product.

Any final demo footage containing third-party games, music, branding or other streamers must be reviewed for permission before submission. Current output/playwright captures are synthetic rehearsal screenshots only.
